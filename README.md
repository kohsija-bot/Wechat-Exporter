# WeChat Exporter

A small independent Windows desktop utility for exporting your own locally available WeChat 4.x chats and media. Built with Python 3.14 and PySide6 (Qt 6). No cloud, scheduler, background service or telemetry.

## Project status

The v2.1.0-beta source import and portable Windows build are pending. This initial README is not a release; no Windows executable is available yet.

## Planned release features

- Chat preview, search, date range and batch export.
- TXT, Markdown, CSV, Excel, JSON, JSONL and offline HTML.
- Media Browser with image preview, video playback where supported, and selected/all visible media export.
- Local processing, progress and cancellation.

## Limitations

Only locally available history and media can be exported. Some encrypted V2 images and missing media cannot be recovered. Real Windows compatibility is not yet fully verified. Use only accounts you are authorized to access.
